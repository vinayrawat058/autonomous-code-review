# Wire a live GitHub App (webhook reviews)

The review pipeline already implements `POST /api/github/webhook`. This guide registers a real GitHub App (recommended) or a repository webhook + `GITHUB_TOKEN` (quick local demo), points it at a public tunnel, and reviews real PRs on `vinayrawat058/autonomous-code-review`.

## What you need

- Docker optional (sandbox falls back to local)
- Groq key already in `backend/.env`
- Cloudflare `cloudflared` (or any HTTPS tunnel to port 8000)
- Browser session logged into GitHub (for App Manifest registration)

## Steps

### 1. Start the API

```powershell
cd backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
```

### 2. Start a public tunnel

```powershell
& "C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel --url http://127.0.0.1:8000
```

Copy the `https://….trycloudflare.com` URL.

### 3a. Register the App (manifest flow — preferred)

Open (replace the host):

```text
http://127.0.0.1:8000/api/github/app-setup?public_base=https://YOUR_TUNNEL_HOST
```

Click **Create GitHub App** while signed into GitHub. GitHub redirects back to localhost; the API writes:

- `backend/.env` — `GITHUB_APP_ID`, `GITHUB_WEBHOOK_SECRET`, key path
- `backend/.secrets/github-app.pem` — private key (**gitignored**)

Then install the App on `autonomous-code-review` (App JWT alone is not enough until an installation exists). Permissions:

- **Pull requests:** Read & write
- **Contents:** Read
- **Metadata:** Read

### 3b. Quick path — repository webhook + PAT

If you only need a live smoke test without creating an App yet:

1. Set `GITHUB_TOKEN` (repo scope) and `GITHUB_WEBHOOK_SECRET` in `backend/.env`.
2. Create a repo hook (example with `gh`):

```powershell
@{
  name = "web"; active = $true; events = @("pull_request")
  config = @{
    url = "https://YOUR_TUNNEL_HOST/api/github/webhook"
    content_type = "json"; secret = "YOUR_WEBHOOK_SECRET"
  }
} | ConvertTo-Json -Depth 5 | Set-Content hook.json
gh api repos/vinayrawat058/autonomous-code-review/hooks --method POST --input hook.json
Remove-Item hook.json
```

The API falls back to `GITHUB_TOKEN` when App credentials are absent.

### 4. Confirm

1. Deliveries (App → Advanced, or repo → Settings → Webhooks) should show `ping` / `pull_request` with HTTP 200/202.
2. Open a small test PR against `main`.
3. A review/comment should appear with a `thread_id` for Studio approve.

## Manifest reference

See `docs/github-app-manifest.json`. The live form is generated by `/api/github/app-setup` so the tunnel URL stays correct.

## Security notes

- Never commit `.env`, `*.pem`, or `backend/.secrets/`.
- The setup UI + callback are available only when `APP_ENV=development`.
- Prefer `SANDBOX_BACKEND=auto|docker` when Docker Desktop is running.
- Quick tunnels (`trycloudflare.com`) are ephemeral — update the webhook URL when the tunnel host changes.
